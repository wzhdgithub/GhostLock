# 404 - 页面不存在

抱歉，您访问的页面不存在或已被移动。

## 可能的原因

- 链接地址拼写错误
- 页面已被重命名或删除
- 访问了不带仓库路径的旧地址（本站正确地址以 `/GhostLock/` 开头）

## 正确地址格式

本站所有页面的正确地址为：

```
https://wzhdgithub.github.io/GhostLock/页面名/
```
